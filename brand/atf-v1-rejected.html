Five ways in

Five above-the-fold options built on the parked Threshold and One Message direction, using the landing page copy word for word. Each shows desktop at 1440 and a designed mobile at 390. Use the switches under each option to try any headline, subhead or microcopy and check the copy fit. The motion is quiet: each option has one small move, and the headline and CTA are readable straight away.

Flags and recommendation

Recommendation

Option 1, Front Door, with headline 1 and subhead 2. It uses the club's real front door and the line from the live site, and it's the strongest first impression for paid traffic. Option 2, The Arch, is the one to A/B test against it. Its white, left-aligned layout carries the longer headlines (2 to 4) better and reads faster. You decide, and one round of changes is included.

Copy-fit flags

  • Headline 4 (70 characters) only fits as a sentence-case statement. It's too long for capitals in options 1, 3 and 5.
  • Headline 2 reads best on two lines, broken at the full stop. Option 3 is built around that break.
  • There's no eyebrow in the copy, so none is shown. If you want one, the King Kong location eyebrow would be "Private club · [Club], [City]".
  • "Apply For Membership" is set in capitals by the button style. The copy itself is unchanged.
